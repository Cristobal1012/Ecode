# Manual de uso del comprador

Guía de EasyShop para la persona que visita la tienda, compra y administra su cuenta. Solicitada para documentar el flujo del comprador por separado del [manual de administración](../manual-uso-panel/README.md).

- [PDF para entregar al usuario](Manual_de_uso_del_comprador_Ecode.pdf).
- [Word editable con las capturas incorporadas](Manual_de_uso_del_comprador_Ecode.docx).

Versión 1, actualizada el 14 de noviembre de 2026. Tiene 44 páginas, pasos numerados, índice con enlaces y capturas de una tienda ficticia. El contenido corresponde a `main` en `15562e5`, que incluye los cambios de la rama `emilio` en `7f574ce`.

Las suscripciones incorporan las correcciones de SCRUM-202: elegir un exclusivo permitido desde la contratación, cambiar su variante mientras se espera el primer pago y respetar su indisponibilidad en una suscripción pausada. Se distingue ese flujo del carrito normal, que requiere una suscripción activa para comprar exclusivos. También se explican las funciones opcionales y las diferencias entre un pedido pendiente, un pago confirmado y un pago que necesita revisión.

El Word y el PDF se revisaron para comprobar la paginación, los enlaces del índice, la lectura de las capturas y la correspondencia con la interfaz. Los datos personales, bancarios y de pedidos de las imágenes son ejemplos; no se deben utilizar para transferir. No se realizaron pagos reales a proveedores para preparar el manual.

Para actualizarlo, editar el Word, renovar las capturas que hayan cambiado y exportar de nuevo el PDF. Revisar todas las páginas afectadas y comprobar los números y enlaces del índice. Las capturas sueltas, las cuentas ficticias y los archivos de preparación no forman parte de la entrega.
